# 📚 AI-Powered Smart Study Planner 🎯

A lightweight, **frontend-only smart study planner** built using **HTML, CSS, and JavaScript**.  
This planner allows students to dynamically input subjects and topics, automatically recommends high-quality resources, and helps organize study time efficiently.  

---

## **Features ✨**

- ✅ **Any Subject/Topic Input** – User can input any known or unknown subjects.  
- ✅ **Automatic Resource Recommendations** – Curated links for known subjects, generic for unknown ones.  
- ✅ **DFS / BFS Topic Traversal** – Optional algorithm to respect topic dependencies.  
- ✅ **Tick Marks** – Mark topics as completed.  
- ✅ **Motivational Messages** – Encourages users while studying.  
- ✅ **Colorful UI & Cards** – Visual clarity for topics and hours.  
- ✅ **Dark / Light Mode Slider** – Modern toggle with smooth animation.  
- ✅ **Copy Plan Button** – Export your study plan quickly.
